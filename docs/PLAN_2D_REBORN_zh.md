## 0. 三个科学问题,一台仪器

1. **为什么 chorus 在 ~0.5 f_ce 有功率缺口?**(Gao 2019:2/3 事件,
   中心 0.49 f_ce,宽 ~0.07 f_ce)
2. **上带哨声波由什么驱动?**(观测:UB 局限近赤道 |λ|≲15°,Meredith
   2009;UB 内部也有离散元素,Li 2019 Fig 1c)
3. **缺口是如何形成的?** —— 即下面假设空间里哪条因果链真正在运行。

**预注册假设空间**(继承 PLAN_2D v4 + PLAN_UB_1D):

- **H1(无记忆)**:缺口是"分隔"不是"雕刻"——元素爬到 ~0.5 时 Omura
  走廊预算耗尽而停(WHY_NO_060 的走廊分析)、v_g/v_ph 简并、环境 f₀ 在
  V_p(0.5) 处常驻朗道阻尼、或两带来自两个独立源。预言:缺口与首个元素
  同时出现、无分布函数前兆、τ_D>0(权重弛豫)下缺口仍在。
- **H2(记忆 / 平台雕刻)**:斜传播 LB 携带 E∥,朗道共振在
  [V_p(ω_LB), V_p(0.5)] 写出平台;精确简并 **V_p(0.5) = |V_R(0.5)|**
  (ω_pe/Ω_e=5 时两者均 = 0.0995c,已验证)把平台顶边的回旋镜像钉在
  0.5;平台随后回旋阻尼反向传播的 0.5–0.55 波。预言严格因果序:
  **E∥ 做功 → Δf(0.08–0.10c) → 平台 → 0.5 功率下降**,逐元素累积、
  τ_D>0 会抹掉、且有方向敏感性(one-way-street 判据)。
- **UB 机制 A–D**:A 平台切分双成分;B 下带级联(2ω 锁相,唯一在 1D
  PIC 里演示过的);C 多源传播/密度导管;D 注入低能各向异性。

判决这些假设,一个盒子里必须**同时**具备六项能力:
(i) 自生斜传播且 WNA 随纬度演化(E∥ 的书写器);(ii) 0.1–3 keV 电子是
**动理学**的(V_p(0.5)≈0.1c 正落在这个能段);(iii) 足够长的对流增益
runway;(iv) 多元素时长;(v) 噪声地板远低于元素幅度;(vi) 能把每一焦耳
按种群、按共振通道记账的诊断。**没有任何现存代码同时具备六项**——我们的
也不行,这就是重设计的理由。

## 1. 对现有工具的判决(为什么必须重设计)

### 1.1 我们自己的 mirror2d(近轴 slab 条带)——四条结构性缺陷

底层引擎(Yee/Esirkepov、tile-sort、cold_model=full、(E,μ) 加载器、
checkpoint)已验证、全部保留。不合格的是**几何与种群架构**:

1. **没有传播生成的斜化**。G2.2 预注册 ray tracing(精确 prof=3 几何)
   证明:条带里射线只偏 ≤0.6°——近轴 slab(Ly≪Lx)没有可用的磁力线
   曲率。斜波功率只能靠不稳定性自己的 θ 谱。H2 的"E∥ 在 λ~10–25° 写
   平台"与观测的 WNA(λ) 增长(Lu 2019 Fig 5–6)**结构上不可测试**。
   这是最大的一条错。
2. **y 周期 wrap 伪影**。By ∝ ỹ 在 wrap 处跳 2aB₀x̃Ly;跨缝回旋轨道层
   被弹性 pitch 散射(实测层内 dT∥ −10.5% / dT⊥ +5.6% 每 2T_b)。能
   活,但它是一个非物理散射源,恰好坐在缺口物理所在的量(投掷角结构)上。
3. **单 δf 种群坍缩**。v4 转 δf 是对的(full-f 地板 1.3e-3 ≈ 信号;
   δf 2.1e-6),但"恰好一个 δf 热种群 + cold fluid"的 guard 让 UB 问题
   **无法提出**:keV 引擎和 0.1–2.6 keV shelf 无法分开表示、分开记账、
   分开消融。1D 的结构性失败(bimax 的 A 对能量盲 → γ_UB<0 按构造)被
   原样重建进 2D。
4. **度规/归一化卫生是后补的**。局地 f_ce 归一化频带、吸收层在 runway
   外、ρ⊥/dy≥2、探针不进吸收层——全部是 v3 审查当作 run 设计缺陷事后
   发现的,靠分析脚本纪律兜底。重生版把它们做成 deck-finalize 的
   **硬 gate**。

### 1.2 Lu 组 2D gcPIC(Lu 2019 JGR;Ke 2017…2025)——保留什么、怀疑什么

从 PDF 原文核对(docs/lu2019.pdf p.4158–4160;GAP_PLAN Lu 审计):冷电子
= **T=0 流体**(其 Eq.1–3);热电子相对论 full-f PIC;修正正交偶极坐标
(p,q);网格 **64 × 4000**,赤道横向格距 Δ⊥ = 3.13ρ_e0
(ρ_e0 = 0.705 c/ω_pe),沿场 Δ∥ = 0.26–0.68ρ_e0;Ω_e0Δt = 0.02;
ppc ≈ 1000(只有热电子,共 2.56e8);波吸收 + 粒子反射边界(Hu &
Denton 2009);n_h/n_c = 1%,ω_pe/Ω_e = 5,T⊥/T∥ = 6,β∥ = 0.01;
L = 0.6 R_E 拓扑(≈ ×12 压缩,l_re ≈ 1131 c/ω_pe)。

**保留(他们立的行业标准)**:electron-hybrid 闭合(流体冷 + 动理学热);
Chan-1994 力平衡加载(与我们的 (E,μ) 映射代数上恒等,已验证);波吸收
边界;近方形域里真实磁力线曲率(他们的 WNA(λ) 与极向 S∥ 是目标现象学)。

**可疑细节(每条附定罪数字)**:

1. **流体冷按构造杀死平台通道**。缺口的动理学引擎(Li 2019,我们已
   在库复现:平台在 |v∥|∈[0.08,0.10]c → gap/LB → 3e-4)住在
   V_p(0.5)≈0.1c ≈ 0.1–3 keV 的电子里;Lu 系列所有 run 里这些电子都在
   T=0 流体内:没有朗道阻尼、没有平台、没有缺口——事实上**全系列没有
   任何一个 run 出现缺口或两带结构**(Ke 2025 自己承认 UB 需要更细网格)。
   缺口/上带研究不能继承这个闭合。
2. **横向分辨率与他们自己的 WNA 主张矛盾**。Δ⊥ = 3.13ρ_e0 = 2.2 c/ω_pe
   → 横向 Nyquist k⊥ = 1.43 ω_pe/c。他们报告 λ=30° 处 WNA 达 50°
   (Fig 5j),k∥ 到 ~1.4 ω_pe/c,意味着 k⊥ ≈ 1.7 ω_pe/c——**超出自己的
   横向 Nyquist**;40° WNA 时也只有 ~2.5 格/横向波长。Yee 类格点色散在
   2–3 格/λ 时相速误差 O(10–40%):高纬斜波场在数值上是被碾过的,UB 的
   斜化(0.65Ω_e、60° 时 k_tot≈2.3 ω_pe/c)根本表示不了。**全系列 UB
   缺席至少部分是数值原因**,叠加在第 1 条之上。
3. **3D 偶极塞进 2D 的度规歧义**。3D 偶极只有带上方位角度规
   h_φ = r·cosλ 才无散。平面正交 (p,q) 求解器(他们自述"正交坐标系")
   要么带 h_φ(轴对称环波——论文未说明,而且对 chorus 波包是错的),
   要么不带(那么背景的子午面磁通管收窄——他们 Fig 1b 网格里可见——与
   波动方程度规不自洽:WKB 聚焦到 λ=30° 被高估 ~1/√cos³λ ≈ 25%)。
   幅度依赖的结果(chirp 率 ∝ B_w,其 Fig 7e–f 的 Omura Eq.50 对照)
   继承这个系统误差。论文与可得的 gcPIC 方法文献均未写明——**标记存疑,
   不判死刑**。
4. **无损失锥的粒子反射墙**。λ_w = ±34°(R_w = 4.3,等效赤道损失锥
   29°),所有粒子全部弹回。对 Lu 2019 的 t ≤ 3000(≪ T_b ≈ 2e4)影响
   不大;但"重复元素"主张(Lu 2021,更长/1D+注入)的起搏器正是边界/
   补给处理——REFRESH_DESIGN 已记录对其注入率循环论证的批判。
5. **×12 压缩偶极里的 full-f @ ppc 1000**。B_th ∝ l_re⁻⁴(我们在
   ×5–×20 验证):他们的阈值比真实磁层高 ~2e4×,δB/B = 3–4e-2 的元素
   处在真实辐射带从不到访的俘获宽度 regime;同时散粒噪声种子与阈值是
   简并旋钮(我们 lre-scan 的教训)。他们的定性现象学(riser、WNA(λ)、
   极向 S∥)在此之下存活;**定量结论(chirp 率、幅度、onset 时间)不可
   移植**。
6. **电荷守恒未记录**。曲线坐标里 Esirkepov 类沉积并不平凡;论文写了
   ∇·E = ρ/ε₀ 但没写如何维持。无法核实——列出备查。

另:我们的 deck gate 实测发现 Lu 的热电子 ρ/Δ⊥ = 0.32——比我们
full-f 的 ρ⊥/格距 ≥ 2 规则(test_mirror2d:ρ/dy=1 时 2 T_b 内 T⊥ 被
磁化有限网格不稳定性抽到 ×4.6)低 6 倍,且未说明任何缓解措施。

## 2. 重设计

### 2.1 D1 几何:笛卡尔网格上的精确 2D 磁通函数偶极

需求看似矛盾:要真实磁力线曲率(像 Lu 的偶极)、要 2D 波动度规下精确
无散(Lu 的 3D 偶极嵌入保证不了)、要笛卡尔网格(保住已验证的
Yee/Esirkepov/cold_full 内核,避开曲线坐标沉积的坑)。

**线偶极 ψ = M·x/r²(B₀ = ∇ψ × ŷ)同时满足三条**,且性质全是精确的:

- ∇·B₀ = 0 恒等成立;ψ 调和 → ∇×B₀ = 0(真空场,无隐藏线圈电流);
- **|B| = M/r² 精确**;磁力线是过原点的圆:r = L·cosλ(λ = 纬度,
  L = 赤道穿越距离 = 圆直径);
- 由圆周角定理,沿线弧长 **s = L·λ 精确** → 镜像轮廓
  **B(s)/B_eq = sec²(s/L)** = 1 + (s/L)² + … → 赤道抛物尺度
  **l_re = L,正是 1D 代码的同一个旋钮**。L = 1330.5 就是 ×10 几何;
  同 l_re 的 1D↔2D 配对 run 从此是受控实验("35× 对流压制"问题第一次
  有对照);
- δf 机器需要的量全部闭式:L(x,z) = r²/x、∇L、且 **b̂·∇L = 0 精确**
  (沿场运动不换 L;V0 实测 2e-16);
- |∇L| = sec²λ = B/B_eq(磁通守恒)→ 壳层面积闭式
  ΔL·L·(λ_w + sinλ_w·cosλ_w),内存预检直接用;
- B₀ 在 pusher 里解析、永不上网格:Faraday 只碰波场,背景无散性不可能
  被离散化破坏。

诚实代价:2D 类比的镜像比是 sec²λ,同纬度弱于 3D 偶极
(30° 处 1.33 vs 2.13),所以盒子伸到 λ_w ≈ 50° 换取墙镜像比 2.4。
公开声明,不藏——这与所有压缩模拟做的是同类妥协。

域:笛卡尔 (x,z) 盒排除原点,由 deck finalize 从 (L, ΔL, λ_w, 边距)
导出,例如 λ_w=50° 壳层 → x ∈ [0.34, 1.10]L,z ∈ ±0.58L(磁力线最大
z = L/2,在 λ=45°)。波看见整个盒子(非导管传播、折射、跨 L 泄漏是
**被表示的**,不是被截肢的);Umeda 掩模在盒边框内、runway 之外。
**真实曲率回来了**:磁力线真实地弯过笛卡尔网格,WNA 沿传播演化——条带
截肢掉的、Lu 度规处理含糊的那个机制,在这里因为网格是笛卡尔、B₀ 是
解析的而平凡地精确。

面外不变性(∂/∂y = 0)保留——子午面 2D,k_φ = 0,与 Ke/Lu 相同。
方位角漂移只动 v_y、永不移动子午面位置:**磁壳在面内不可能泄漏**
(此几何的面内导心漂移恒等于零),这正是下一节能省钱的原因。

### 2.2 D2 电子模型:cold fluid + N 个动理学 δf 种群(N ≥ 2)

    cold T=0 流体(主体,全盒)
      + δf "engine" 种群:keV、各向异性、L 壳层局域
      + δf "shelf"  种群:0.1–2.6 keV 平台/UB 燃料能段,独立 A₂
      [+ 可选更多种群:pool、第二 L 壳层源、…]

- **多 δf 是一等公民**(单种群 guard 死于架构而非放宽检查)。每个动理学
  种群携带自己的 f₀(E,μ;L) 与**解析** ∂lnf₀——bimax、losscone、以及
  (新的、必做的)prodkappa/conecut 导数——自己的权重台账、沉积标签、
  fv/J·E 诊断。"engine 还是 shelf"是逐种群读数,不是推断。这是 UB
  问题能被提出的前提:1D 史的结构性失败正是单 bimax 的 A 对能量盲。
- 弯曲几何的 δf 契约:dw/dt = −(1−w)·dlnf₀/dt,
  dlnf₀/dt = (∂lnf₀/∂E)Ė + (∂lnf₀/∂μ)μ̇ + (∂lnf₀/∂L)(v·∇L),三个因子
  全闭式。τ_D 作为 deck 旋钮存在但**默认 0**,是 H1/H2 判决臂(v4 裁决
  原样继承)。
- **壳层紧致加载**:热 f₀ 带 raised-cosine 的 L 轮廓(宽 ΔL≈40 c/ω_pe);
  δf marker 只存在于 f₀>0 处。marker 数 ∝ **壳层**面积而非盒面积——这
  就是弯曲 2D 今天就跑得起的原因(§4)。cold fluid 填满全盒(数组便宜),
  是全域的波传播介质;deck 驱动的 n_c(x,z) 轮廓使导管/多源臂(UB 机制 C)
  成为可能。
- **冷流体非线性开关**(新物理能力):已验证的流体是线性化的——这会
  **无声地关掉 UB 机制 B**(下带级联需要二阶密度/速度拍频;Lu 的流体
  Eq.1–2 保留 ∇·(n_cV_c) 与 (V_c·∇)V_c,我们的线性化丢了)。deck
  `[cold] nonlinear = 0|1` 加回二次项(显式、同 stagger)。默认 0
  (干净线性响应平台);级联臂与 full-f 交叉验证用 1。不加这个开关,
  级联阴性结果就是一个预注册的假阴性——这开关是"机制 B 不存在"与
  "机制 B 被截肢"的区别。

### 2.5 D6 诊断(台账就是实验本身)

全部按物理时间定节奏、checkpoint 一致、带种群标签:
