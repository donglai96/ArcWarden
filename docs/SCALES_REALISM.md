## 3. 核心洞察:压缩尺度的代价 = 我们全部点火史的统一解释

Omura 阈值 **B_th ∝ a² ∝ lre⁻⁴**(in-house 于 x5–x20 验证,
scripts/omura_threshold.py)。把两种噪声地板(full-f 实测 1.3e-3;
δf 实测 2.1e-6 @wdnoise=1e-3)与 B_th@0.25Ωe 排序:

| 尺度 | B_th@0.25 | full-f 地板 1.3e-3 | δf 地板 2.1e-6 |
|---|---|---|---|
| x20 (665) | 2.0e-2 | 15× 阈下 → 死寂 ✓(实测 suppressed)| 深阈下 |
| x10 (1331) | 1.244e-3 | **≈恰好在阈值上** → threshold-gated 单 riser ✓ | 600× 阈下 → **D3a 死寂 = 必然** |
| x4 (3326) | 3.2e-5 | 40× 阈上 → 快速点火+停滞列车 ✓ | 15× 阈下 |
| **x1 (13305)** | **~1.2e-7** | **10⁴× 阈上 = 永久人工风暴** | **~17× 阈上 = 从散粒噪声自然点火** |

三个结论:
1. **D3a/D3b 的"点火危机"是压缩伪影**,不是物理。x1 时同一 f0 从 δf
   散粒地板自然点火;而且盒长 10× → 对流增益 N_g=∫γ/vg ds 同步 ×10,
   35× 对流压制问题(2D 实测,D2 定标)也一并缓解;
2. **x1 时 full-f 不是"更真"而是错的**:其固有噪声 10⁴× 超阈 = 永久风暴,
   物理时序全被噪声点火淹没 → **δf 在现实尺度是必需品,不是妥协**;
3. **wdnoise 是点火旋钮**:x1 下 wdnoise 1e-3→浅阈上(自然点火),
   1e-4→2e-7≈阈值(可控点火研究)。"点火可控"从工程缺陷变成实验设计能力。
4. 顺带:现实 nh~0.3%、A~0.5 之所以在现实中够用,正因为 B_th(x1) 极低
   ——我们过去被迫 nh 1.8%/A 5 是在补偿压缩的 lre。**近现实 run 可以第一次
   用观测的 f0 参数**。

## 4. 边界条件全清单(判决与现实差距)

| 边界 | 机制 | 程序判决 | 现实差距 |
|---|---|---|---|
| x=damping | 吸场层(nd 240)+粒子镜面反射 | Phase-Q 验证清白;δf 唯一兼容(反射保 wd) | 波全吸(电离层实际部分反射);无沉降损失;吸收层必须在物理 runway 外(v3 缺陷 7)|
| x=hybrid | damping + u⊥ 剥离层 | **剥离宽度是杠杆**:1-cell 无效 vs 300-cell 出元素(07-28);soft≈hard(已证伪) | 破坏 δf 权重方程 → 仅 full-f;扭曲 pitch 分布(v3 缺陷 6)|
| 1D atmo/cone 墙 | 墙在 MLAT 40°,batm=7.4 | atmo40 主力验证 | 墙等效锥 21.6° vs 真实 3.8°;Chen2026 的 ±20° 墙反射 58% 种群(我们的批判,在案)|
| refresh 浴 | 薄壳 f0 重采样 | **燃料非触发器**;放 15° 会抹掉中纬对流放大(rp_soft 教训);湍流中守恒 PASS | 真实 refill = 等离子体片注入,非局部重采样 |
| y 周期 | mirror By 带 wrap 跳变 | ke17 极端情形存活(straddler 0.6%)| 无方位角漂移/3D ducting |
| 种子 | bnoise 白噪(寿命≈1 次穿墙 ~900/Ωe);天线(tao17 电流幅标定);full-f 固有噪声;δf wdnoise 旋钮 | D3a 实测种子被墙吃 | 现实种子=环境湍流,x1 时 δf 地板即可扮演 |
| **未实现** | 部分电离层波反射;开放粒子边界+注入(真 refill);碰撞大气层 | — | 近现实 run 的边界工程项 |

## 7. 工程缺口(按解锁价值排序)

1. **chirp2d 接 δf**(∂lnf₀ 机制从 mirror2d 移植;biMax/losscone 可用)
   → 解锁 R0,**当前 5090 立即可跑**;
2. 多 GPU x-域分解(场 halo + 粒子迁移 + 分 rank tile-sort)→ R2+/R3;
3. 内存杠杆:sort-chunking(去双缓冲)+ w/wd-fp16 → 60→~40 B/marker
   (fp16 仅用于权重,位置/动量保 fp32 —— 全 fp16 已裁定否决);
4. 现实边界:部分电离层反射系数 + 开放注入边界(真 refill);
5. ckpt 嵌 git hash(溯源,已知缺口);长时程 run 的离子背景假设审查。

## 8. 预注册风险

- lre⁻⁴ 从 x5–x20 内插验证过,**外推到 x1(再 4×)未验证** → R0 的首要
  产出就是验证它;若 x1 阈值高于预言,排序表按实测重排;
- 2D 35× 对流压制随 lre 的变化未知(R1 前用 R0/短 2D 标定);
- δf 线性化在元素幅度(1e-2)下的有效性由 wd_max<0.3 gate 把守,
  大 GPU 上补一臂 full-f 交叉验证(R3);
- 2D 槽几何永远缺方位角漂移与 3D ducting —— 如实出局声明,不假装。
