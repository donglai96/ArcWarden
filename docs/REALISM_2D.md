## 2. 报告纪律(预注册)

**允许带出模拟的结论**(压缩不变量):
- 机制判别与因果结构:H1 vs H2 判决、E∥ 做功 → Δf(0.08–0.10c) →
  平台 → 0.5 功率下降的时序、方向敏感性(one-way street)、

  幅度、l_re-free);

**不允许直接外推到真实磁层的量**(l_re⁻⁴ 污染):
chirp 率、onset 时间、绝对阈值、绝对幅度、元素重复周期。这些只能以
"×10 几何下的值"报告,并且必须同时给出同 l_re 一维对照值。任何论文
图表引用这些量时,标题/图注必须带压缩因子。

**双归一化规则**(已入代码):所有频谱产品同时报 ω/Ω_e(local) 与
ω/Ω_e,eq;probes 的局地 Ω_e 写入 meta.txt(实测 = sec²λ 精确)。

## 补遗(2026-08-19):元素时长的定量账 —— 为什么我们的 riser 比观测短 ~200×

V4R5-A5 的实测:元素 Ωe·τ ≈ 60–100(约 4–6 个载波周期),扫频率
2.7e-3 Ωe²,B_w/B0 ≈ 2.4–3.9e-2。真实磁层(L≈4.5,fce≈9.6 kHz,
取相同 ωpe/Ωe=5 → n_e≈29/cc,c/ωpe≈1.0 km):元素 0.1–0.5 s →
**Ωe·τ ≈ 6e3–3e4**;扫频率 1–20 kHz/s → **1.7e-6–3.5e-5 Ωe²**;
幅度 10–300 pT/342 nT → **B_w/B0 ≈ 3e-5–9e-4**。

**因果链(全部对上)**:τ = Δω/(dω/dt),而 dω/dt ∝ B_w(Omura,
V4R5 已按元素验证,median 比值 0.98)。我们的 B_w/B0 高出观测
30–1000×(A=5 的饱和幅度),扫频率因此快 ~100×,同样 ~0.2 Ωe 的
扫幅便只剩 1/100 的时长。几何压缩(l_re=2309 vs 真实 1.36e4 c/ωpe,
×5.9)是次要贡献(影响释放点与终止,不改赤道扫频率)。

**为什么观测的 STFT 干净**:真实元素的时间-带宽积 ≈ 200–1000 个
独立时频单元;我们的元素只有 ~3 个 —— 块状谱图是元素本身短,
不是采样率(Nyquist=26 Ωe)也不是分析方法(重排谱已贴近不确定
性极限)。ΔL=60 shell 内 fce 相差 4.5% 的多列源各自独立 chirp,
探针看到的是叠加 —— 加剧了"辫状"形态(真实卫星单点单磁通管,
元素又长,自然清爽)。

**A 阶梯的预登记推论**(rate ∝ B_w 线性外推,B0eq=0.2):

| 驱动 | 预期 B_w/B0 | 预期 dω/dt (Ωe²) | 预期 Ωe·τ | 元素步数 |
|---|---|---|---|---|
| A=5(本次) | ~3e-2 | 2.7e-3(实测) | ~74 | ~2.4k |
| A=3 | ~1e-2 | ~8e-4 | ~240 | ~7.8k |
| A=2 | ~6e-3 | ~5e-4 | ~390 | ~13k |
| A≈1.5 | ~3e-3 | ~2.5e-4 | ~790 | ~26k |
| 观测幅度 | ~3e-4 | ~2.5e-5 ✓(落在观测窗内) | ~7.9e3 ✓ | ~260k |

约束:full-f 噪声底 δB/B≈1.3e-3(ppc=100)→ A≈1.5 的饱和仅高出
底噪 2.3×(边缘可行,ppc↑ 直接改善);观测级幅度(3e-4)低于
full-f 底噪,只有 δf(底噪 3e-7,待验证)可达 —— 这就是 ppc 提升
与 δf 验证两条线的定量理由。B_th ∝ lre⁻⁴ 对我们有利(压缩少)。
