## 2. 报告纪律(预注册)

**允许带出模拟的结论**(压缩不变量):
- 机制判别与因果结构:H1 vs H2 判决、E∥ 做功 → Δf(0.08–0.10c) →
  平台 → 0.5 功率下降的时序、方向敏感性(one-way street)、
  "缺口是否需要 E∥ 通道 / 上带需要哪类燃料"的结构性结论;
- 以正确无量纲量组织的标度律(先例:Chen2026 复现证明 sweep rate ∝
  幅度、l_re-free);
- 同 l_re 的 1D↔2D 受控对照(l_re = L 精确匹配正是为此设计)。

**不允许直接外推到真实磁层的量**(l_re⁻⁴ 污染):
chirp 率、onset 时间、绝对阈值、绝对幅度、元素重复周期。这些只能以
"×10 几何下的值"报告,并且必须同时给出同 l_re 一维对照值。任何论文
图表引用这些量时,标题/图注必须带压缩因子。

**双归一化规则**(已入代码):所有频谱产品同时报 ω/Ω_e(local) 与
ω/Ω_e,eq;probes 的局地 Ω_e 写入 meta.txt(实测 = sec²λ 精确)。

## 3. 逃逸路线:W1 阶

内存阶梯(PLAN_2D_REBORN §4)的存在理由:同一个 deck 把 L0 改成
13305(W1,~170 GB,B200/GB300)= **第一个真实梯度尺度的 2D chorus
模拟**。那里 B_th 降到 ~10⁻⁷ 量级,观测水平的 f₀(n_h~0.3%, A~0.5)
从 δf 散粒地板自然增长——A=5 类人为放大第一次可以扔掉,而 ×10 run
(V4/W10)转为它的受控压缩对照组。SCALES_REALISM §3 的三个预言
(x1 自然点火、full-f 在 x1 是永久人工风暴、wdnoise 是点火设计旋钮)
在 W1 首跑时验证。

## 4. 与 Lu 2019 的失真对比(同类压缩,谁更接近现实)

| | Lu 2019 gcPIC | 本分支 V4/W10 |
|---|---|---|
| 压缩 | ×12(l_re≈1131) | ×10(1330.5)——相当 |
| A, n_h | 6, 1% | 5, 1% ——相当 |
| 种子 | full-f 散粒噪声(ppc 1000,不受控) | δf wdnoise(受控,低 3 个量级) |
| 二维无散性 | 度规歧义(±25% WKB 聚焦不确定) | 精确(磁通函数构造) |
| 0.1–3 keV 电子 | T=0 流体(平台通道结构缺失) | 动理学 δf |

上带可分辨**——四项都是 Lu 系列"从未出缺口/上带"的候选原因,
在本分支被逐一移除。
