# V4R10 中途复盘(2026-08-19)——"波形怪、没有 chirping element"的诊断报告

## 一句话结论

**波没有坏,是还没到时候 + 探针看错了地方。** 现在 t=21000(140k 步)
仍处于线性增长段,振幅只有出元素门槛的 ~1/12;而且主探针线 L0=4000
偏离波功率脊(L≈4020–4050)30 倍功率。按实测增长率外推,饱和入口在
**~236k 步**,原定停点 195k 和续跑目标 235k **都到不了 element 窗口**。

## 1. 代码详查结果:没有发现 bug

逐行看了 warden2d.cu、diag2d.hpp、background2d.hpp、deck2d.hpp、
kinetic2d.hpp:

- **探针采样本身是对的**:探针沿 L0(和 L2=4030)场线按纬度取点,
  场旋到场向坐标系(E∥、E1、Ey、B∥、B1、By),旋转矩阵、Yee 交错
  偏移、局地 Ωe 记录都核对无误;
- **加载器/δf 权重方程**与设计文档一致(gc-L 剖面参数、时间居中
  权重更新、纯波力项),8-18/8-19 review 修复都在;
- δf 健康:140k 步时 wd_rms = 8.1e-3(闸 0.25),runaway 全程 0。

问题不在代码,在**测量位置**和**停点校准**两处运行设计上(下述)。

## 2. "怪波"是什么:线性段的全局模,不是坏波

谱图上那些 0.2–0.45 Ωe 的**固定频率水平条带**(不动、不升调)是
有限源区的线性全局模(离散本征频率梳)。判定证据:

- **V4R9 在同等振幅阶段形态一模一样**(review_v4r9_compare.png 左
  中两图):V4R9 的 element 也是 t≈22000 进入饱和后才出现的;
- 当前 δB/B0 ≈ 1.7e-3,离 V4R9 出元素时的 1–2e-2 还差一个量级——
  chirping 是非线性俘获现象,线性段本来就不该有;
- Hovmöller 图(review_hovmoller.png):波在**赤道 ±10° 出生**、
  沿场线双向传播、在 runway 外被吸收,边界无反射条纹——传播链路
  健康。波场放大动画 review_wavemap.gif(14 帧,3600<x<4300)
  可直接看波从赤道长出来的过程。

## 3. 探针位置:你的怀疑属实(定量)

赤道功率-L 分布(review_powerL.png,4 个时刻):

- 功率脊稳定在 **L≈4020–4050**,峰值在 ~4038 —— 紧贴 shell 外侧
  平顶边缘(平顶 3955–4045)。与 V4R8 的外侧列选择完全同机制:
  线长 ∝ L、Ωe ∝ L⁻³,全局模永远挑最外侧的满密度列;
- **L0=4000 探针:比脊低 ~30 倍功率**(所以那里的谱图最"怪");
- **L2=4030 探针:只比脊低 ~3 倍,可用**。

推论:**加宽 shell 不能消除外缘选择**——增益对 L 单调,脊只会跟着
新外缘走(这次 dL 60→90,脊就从 ~4030 挪到 ~4038)。"再加长 shell"
只会把脊再往外推,还会进一步摊薄增长(见下)。

## 4. 停点校准错了:这是必须改的硬数字

- 实测 γ_W:V4R9 = 4.75e-4,V4R10 = **3.47e-4(慢 1.37 倍)**——
  加宽 shell 的副作用(能量摊到更多列上);
- 同时刻对比:t=21000 时 V4R9 W=1.0e-2,V4R10 只有 4.3e-4(差23倍);
- 外推(review_growth.png):V4R10 到达 V4R9 饱和入口水平
  (W=6.2e-2)在 **t≈35400 = 236k 步**;
- element 干净窗 = 饱和入口 + ~40k 步 → **约 236k–276k 步**。
- 原 deck 的 195k 和续跑命令的 235k 都停在饱和入口**之前**——继续
  按原命令跑完也看不到 element。这就是"当前 run 给不出正确结果"
  的真正含义:不是物理错,是会在出结果前停机。

## 5. 选项(你来定)

**A. 直接续跑到 280k(推荐,最便宜)**
`--nsteps=280000`,再跑 140k 步 ≈ 3.7 小时。探针不动:element 判定
以 L2=4030 为主(距脊 3 倍内),L0 作第二条线。C1"两条线都可见"
按冻结判据执行,若 L0 因偏脊 30 倍而看不见,如实报 FAIL 并注明原因。
风险:比 V4R9 多泡 1.6 倍时长,wd_rms 到停点预计 ~0.2-0.7,C4 有
挂的可能(挂了也是如实报)。

**B. 续跑前把 probe_L2 改到 4040**
一行 deck 改动,resume 时探针线即切换(meta.txt 会重写)。我已把
probes/probes2/energy/sline 精确截断到 140k 步检查点,切换点干净
(样本 35000 之前=旧线 4030,之后=新线 4040)。代价:probes2 前半段
与后半段不同线,分析要分段;好处:element 窗测量正压在脊上。

**C. 重设计 shell 让脊落在设计位置(成本高)**
把源做成单列(dL 小、edge 大的纯高斯)或梯度补偿,让增益峰在 L0。
= 承认全局模选单列,主动把它放到设计处。需重跑全程(~7h),且
纯高斯源的 γ 会更低。**不建议现在做**——先用 A/B 拿到 element 窗,
两带(0.5 gap)判定 C3 本来就是逐探针按局地 Ωe 归一的,脊在 4038
不妨碍科学结论。
