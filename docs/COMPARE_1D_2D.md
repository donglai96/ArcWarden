# 1D(chirp2d)与 2D(pic2d)的深度对比(2026-08-18,以 V4R3 配置为准)

## 1. 物理模型的本质差别

| 方面 | 1D chirp2d | 2D pic2d |
|---|---|---|
| 坐标 | 单根磁力线的弧长 s | 子午面 (x,z),一束磁力线 + 全平面的波介质 |
| 波 | 只有平行传播的横向分量(Ey,Ez,By,Bz),**E∥ ≡ 0 是结构性的** | 完整六分量 Maxwell:斜传播、wave normal angle 随传播演化、E∥ 存在、跨 L 折射 |
| 粒子的回旋运动 | 导向中心式处理:携带 u⊥ 大小与相位 ζ,mirror force 为解析项,**回旋轨道不在网格上** | **完整回旋轨道在网格上解析**;μ 是演生的近似不变量而非模型假设 |
| 由此产生的 2D 特有问题 | 无 | ρ⊥/dz ≥ 2 规则、导向中心 L 的权重方程处理、回旋尺度的网格加热——这些在 1D 中原理上不存在 |
| 背景场 | B0(s) 一维解析轮廓 | 二维解析磁通函数(dipole2d:真实偶极线形,B_eq ∝ L⁻³) |
| 可研究的问题 | chirping 机制、阈值、重复序列 | 上述全部,加上 gap 假设 H2 的 E∥ 通道、upper band 的四种候选机制、WNA(λ)、多源传播 |

## 2. 速度差异(实测数字)

- pic2d 当前:**186 ms/step**(3.49 亿粒子 + 2.12 亿网格),即 1.9×10⁹
  粒子步/秒;其中场求解部分约 88 ms(网格巨大是 2D 特有成本——1D 只有
  数千个格点,场求解可忽略)。
- legacy 优化后的 2D EM 基准(小网格、融合内核):1.55×10¹⁰ 粒子步/秒
  ——比我们快约 8 倍,原因:其网格仅 39 万格(场数组全部驻留 L2)、
  内核融合并做共享内存暂存、无解析背景场与导向中心计算。
- 换算到物理问题:同样跑到 t = 6000/Ω_e,1D(数千格点、数千万粒子)
  需要几分钟到几小时;2D V4R3 需要约 10 小时。**2D 的成本约为 1D 的
  20–100 倍**,来源是粒子数(壳层面积对线)与场网格(面积对线)。
  分工结论:**参数扫描用 1D,机制判定用 2D**。

## 3. 边界条件与模拟区域

- 1D:两个端点即边界;反射墙纬度直接决定等效 loss cone;波在端点被
  Umeda 层吸收。
- 2D:四周为波吸收框;粒子墙只在磁力线的高纬端。V4R3 的具体几何:
  - 壳层内所有磁力线都从**内侧 x 边界**穿出(λ ≈ 48.6–48.9°,跨壳层
    仅差 0.3°——事实上的反射纬度非常一致);z 方向的墙对壳层粒子
    永远碰不到(需要 L > 5800 的线才会到达);
  - 有效反射点 mirror ratio ≈ 5.7,等效 loss cone ≈ 24.7°(真实磁层
    为 3.8°——所有压缩模拟共有的妥协,已在 REALISM_2D 登记);
  - 外侧径向边界无粒子墙:面内导向中心漂移严格为零,粒子不可能跨 L
    逃逸(几何性质,非近似);
  - **内侧强场角落的已知局限**:盒子最内侧 Ω_e 高达 ~10,当地
    ω·dt > 1,该区域的高频波在时间上欠分辨——但该处无粒子、场被
    吸收框阻尼、冷流体旋转为精确算法,故无稳定性问题,只是该角落
    的波物理不可信(也不需要可信)。

## 4. 初始粒子的 L-shell 范围

V4R3:平顶区 **L ∈ [3980, 4020]**(ΔL/L = 1.0%),高斯边缘延伸到约
[3956, 4044](2.2%)。这是一束很细的磁通管:波源在 L 方向是薄的,而
波可以在整个盒子(L 从约 1100 到 6000 以上)传播——跨 L 折射与传播
是解析的,波源的径向结构不是。要研究 ducting 或多源机制时,加宽 ΔL
或加第二个壳层即可(内存按壳层面积线性增长)。

## 5. Debye 长度与格距的关系

这里有一个容易误解的要点:**冷电子是 T=0 流体,没有 Debye 尺度**——
这正是 electron-hybrid 方法的意义:格距不受冷等离子体 Debye 长度约束
(全动理学代码如 OSIRIS 必须 dx ≲ 数个 λ_D,否则网格加热)。约束
转移到两处:

1. **动理学热种群的 Debye 长度**:λ_D,hot = u_th/ω_p,hot =
   0.141/√0.01 = **1.41 c/ω_pe**,即 λ_D,hot/dx = **5.6**——远离
   网格加热判据,安全;
2. **回旋半径规则(2D 特有,更紧)**:ρ⊥/dz 在赤道 5.6、20° 处 4.0、
   runway 边缘(35°)2.20(deck 硬性检验值)、有效墙(48.7°)处降到
   0.99——墙区(35–48.7°)低于规则,已预先登记用 fv 分区温度监测
   该区域是否出现异常加热。
3. 对照:V3 的 Li 基准是全动理学(冷种群也是粒子),其冷 Debye 长度
   dx/λ_D = 4.5,处于边缘——这继承自 Li 原文的设置,legacy 当年
   实测 Esirkepov + filter 把冷种群加热压到 −0.7%,属已知并可接受。

## 6. 时间步长的约束来源(两码不同)

- 1D:波的 CFL(横向 EM)为主;回旋运动不在网格上,Ω·dt 只影响
  mirror force 的精度。
- 2D:光速 CFL(0.15 < 0.177)+ **回旋分辨**(壳层内 Ω·dt 从赤道
  0.030 到墙区 0.171——精确 Rodrigues 旋转保证稳定,精度在墙区略降)
  + δf 运行时权重方程的刚性(当前 full-f 不涉及)。

## 7. 单位换算提醒

1D 文档用 Ω_e0 = c = 1;2D 用 ω_pe = 1, c = 1(Ω_e = 0.2)。对比谱图
与时间轴时:2D 的 t 乘 0.2 得到 1D 惯用的 Ω_e t;长度乘 0.2 得到
c/Ω_e 单位。
