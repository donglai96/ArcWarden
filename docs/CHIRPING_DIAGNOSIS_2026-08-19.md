## 2. 病因一:δf 没有自发辐射(仓库自己的实测裁定)

HOT_REP_ROUND1.md(chirp1d/chirp2d 都测过):

> "Delta-f with the antenna off **stays empty**(no spontaneous
> emission — the marker noise is wd-weighted)"

物理:chorus 的离散元素是"不断有新胚胎被触发"的过程。full-f 的
离散粒子噪声就是真实的自发回旋辐射,**持续地**在增长率最大处
播种胚胎——一个元素烧完,下一个胚胎接着来,这就是离散元素序列。
δf 的 wd 噪声只是 t=0 撒的一次性白种子:线性阶段增益最大的全局
模从这个种子里被放大并**锁定**,之后再无播种。所以我们看到的是
0.2–0.45 的固定频率梳(有限源区的本征模)越长越亮,而不是一个个
出生-扫频-死亡的元素。V4R9 里那些"互相重叠的快元素"是饱和后
非线性破缺挤出来的,天生就乱。

仓库里 δf 出干净元素的唯一配方是 **δf + 触发天线**(Tao17 recipe,
chirp1d run 8 / tao17 臂):把胚胎显式注入。warden2d 没有天线。

δf 方程本身(E,μ 不变量形式、时间居中、gc-L、丢 ∂_L 项)这次
逐行复查无错;附带两个已知边界:深饱和 wd 负尾(V4R9 min −208)
退化后期保真;losscone/conecut 无解析 dlnf0,δf 用不了带损失锥的
f0(atmos 自洽配方因此也是 full-f 专属)。

## 3. 病因二:L0=4000 的等效 lre 落在错误走廊("2D 尺度"的真相)

换算:2D dipole2d 沿场线 B/Beq ≈ 1+3(s/L0)²;1D dipole
B ≈ 1+4.5(s/lre)² → **lre_eff = √1.5·L0**。L0=4000 → lre_eff=4899,
位于 1D lre 扫描的 x2(6653)与 x4(3326)之间。而 1D 分岔实测:
**x10(1330)= 干净元素爬到 0.68 / x8 = flood 边缘 / x6 = 元素停在
0.40 超优幅度 / x5 = 复合体**。我们的 2D 箱子在 1D 语言里根本不在
干净元素区间。

Omura 走廊定量(scripts/omura_threshold.py 公式,biMax):

| 配置 | B_th(0.25) | B_th(0.3) | B_opt(0.3) | 门槛状态 |
|---|---|---|---|---|
| V4R10 (lre_eff 4899, A=3) | 5.7e-5 | 1.5e-5 | 6.8e-3 | **无门槛**:噪声即点火,人人生长 |
| lurepro_x10 (1330, A=5) 已证干净 | 5.5e-3 | 1.6e-3 | 8.4e-3 | 低频关死 + 0.25 处 th≈opt = **选择器** |
| 拟议 2D x10 等效 (L0≈1086, A=5) | 1.2e-2(关死) | 3.5e-3 | 8.4e-3 | 0.3 以下关死 → 元素生于 0.3–0.4 |

干净离散元素的本质是**阈值门槛做选择器**:低频走廊关死、出生频率
处 B_th≈B_opt,一次只放行一个幅度够格的胚胎。V4R10 的门槛比噪声
还低 → 全频带多模并发 → 频率梳 + 复合体,这正是 Chen regime map
的 threshold≈floor 状态。所以"2D 尺度不够"方向反了:**箱子要缩小
~13 倍(L0→~1100),不是加大**。附带修正:加宽 shell(dL 60→90)
让源更均匀,是朝错误方向又走了一步(γ 实测降 1.37×)。

## 4. 病因三(次要,2D 特有):窄 shell 环形 duct

横向仅 ~8λ∥ 的环形源 = 波导:离散径向模、外缘列选择(增益 ∝L
单调,脊永远贴外平顶边)、跨列 Ωe 展宽 6.75%。加上有限源对流
折减(A=3 时单程增益只剩均匀解的 11%,A=2 已到全局阈值边缘),
弱驱动在 2D 被进一步边缘化。1D 没有这些;Lu 2019 的 2D 用宽源。
这条解释"元素为什么乱和弱",但排它性不如前两条——按处方一
缩箱后它自动缓解(走廊门槛会压制旁列)。
