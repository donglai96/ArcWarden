# PLAN_SPARSE_GRID — 把算力与显存集中到有效区域(2026-08-18)

用户提出的问题:矩形网格的大部分区域既无粒子也无我们关心的波,却参与
场求解并占用显存。能否在无粒子区域用粗网格或不放网格?

## 一、问题的定量描述(V4R3 规模)

| 区域 | 占矩形面积 | 现状 |
|---|---|---|
| 粒子壳层 | **1.6%**(3.5e6 / 2.12e8 格) | 粒子内存已按壳层分配(设计如此,无浪费) |
| 波活动带 L∈[3200,4800] | 43% | 场更新已可跳过带外(上一提交),但**显存仍按全矩形分配** |
| 其余(内侧低 L、四角) | 57% | 纯浪费:13 GB 场数组中约 7.4 GB、以及此前一半的场计算时间 |

每步 186 ms 的构成:粒子部分约 98 ms(已经只在壳层内),场部分约
88 ms(带跳过后预计约 40 ms)。**剩余的最大浪费是显存**:场数组
13 GB 中超过一半属于永远为零的区域——这些显存如果释放,可以直接
换成更高的 ppc、更宽的带、或更大的 L₀(更接近真实)。

## 二、四个方案的评估

### 方案 1:分块变分辨率(两级网格,AMR 式)
带内赤道区(|λ|≤25°,upper band 所需的最细分辨率)保持 dx=0.25,
高纬区与带缘用 2 倍粗格。物理依据成立:固定 ω 的 whistler 向高纬
传播时 Ω_e 增大、k∥ 减小,波长变长,所需分辨率确实降低。
**风险**:Yee 格式在粗细交界处有众所周知的伪反射(FDTD subgridding
的经典难题),必须证明界面反射低于 δf 噪声本底才能用于 gap 类
三个数量级的功率测量。**评估:收益中等(带内高纬约占带面积一半,
粗化省约 40% 带内格点),风险与工程量高。列为二期,仅在一期后
profiling 仍指向场开销时才做。**

### 方案 2:稀疏分块存储(单一分辨率)★ 推荐
保持 dx=0.25 不变,但**只为活动 tile(16×16 格块)分配存储**:
tile 池 + 索引表(全矩形 8.3e5 个 tile 的索引表仅 3.3 MB;非活动
tile 读取返回零、写入丢弃)。
- **显存**:场从 13 GB 降到约 5.6 GB(43% 带)——释放约 7.4 GB;
- **计算**:与现有带跳过相当(略优:连非活动 block 的启动扫描都省去);
- **物理零风险**:单一分辨率,无界面反射问题;活动区内与稠密网格
  **逐位等价**(可直接验证);
- **工程量**:2–3 天。所有场 kernel 的寻址(含 filter7 的共享窗口)、
  掩模、诊断采样、快照输出(重构为稠密再写盘)、checkpoint(存池 +
  索引表)都要过一遍;有完整的既有 gate 体系兜底。
- **额外好处**:tile 池 + 索引表正是多 GPU 分域需要的数据结构——
  这一步同时是分域工作的地基。

### 方案 3:曲线坐标贴体网格(gcPIC 路线)
网格直接取 (L, λ) 坐标贴住磁通管。**否决**:这正是设计文档
§1.2 批判 Lu 的路线——度规复杂性、无散性歧义、曲线坐标下的电荷
守恒沉积,全部会回来。笛卡尔网格 + 解析背景场的精确性是本分支的
立身之本,不能为了省格点推翻。

### 方案 4:缩小矩形(降低 λ_w)
墙从 50° 收到 40° 只把面积降到 75%——弯曲磁通管决定了矩形的
包络,收益太小。否决。

## 三、推荐计划

**一期(方案 2,预计 2–3 天):稀疏分块存储。**
1. `FieldViews2D` 寻址改为 tile 池 + 索引表(`idx()` → tile 查表 +
   块内偏移;非活动读零);
2. 全部场 kernel、掩模、诊断、快照、checkpoint 适配;
3. 验证阶梯:(a) 活动区与稠密网格逐位对照;(b) 全部既有 gate 重跑
   (V0/V2/吸收层/V1/V3 快速臂);(c) V4R 规模基准测速与显存实测;
4. 验收指标:场显存 ≤ 6 GB(V4R3 带),全部 gate 绿,速度不劣于
   现有带跳过版本。

**释放的显存直接兑换成物理**(V4R3 几何,32 GB 上限):

| 用法 | 现在 | 一期后 |
|---|---|---|
| ppc | 100 | **150–170**(每波长统计超过 legacy 判定线约 1.6 倍) |
| 或 L₀(压缩比) | 4000(×5.8) | **约 5000(×4.6)** |
| 或 双种群 | 不可(显存不够) | engine + shelf 同时加载(W10 科学配置在此几何) |

**二期(可选,一期后按 profiling 决定):静态两级网格**(高纬 2×
粗化),前提是证明界面反射低于 δf 噪声本底;若一期后场开销已降到
每步 20% 以下,则二期不做,转向粒子侧优化(tiled kernel 的共享
内存场暂存)与多 GPU 分域。

**并行小项**(不依赖上述):Nsight 定位场管线中约 50 ms 的未解释
开销(审查文档 D2 项)——有可能一并消失或指向更简单的修复。

## 四、不做什么(边界)

不改变 dx=0.25 的分辨率契约(res/UB 硬性检验不动);不引入曲线
坐标;不在一期引入多分辨率;背景场 B₀ 保持解析、处处存在。
