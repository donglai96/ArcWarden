## 形态学解释(映射到已验证的一维分类学)

1. **为何是"持续波包列车"而非离散单 riser**:阈值排序决定 regime。
   B_th ∝ l_re⁻⁴:在 l_re=2309 处 B_th(0.35)≈7.5e-5,而 full-f ppc100
   噪声地板 ≈1e-3——**地板高于阈值 ~13 倍**。一维 lre-scan 分类学
   (SCALES_REALISM §3):地板≈阈值 → 阈值门控离散元素(×10);地板
   ≫阈值 → 快速点火 + 停滞元素列车(×4)。我们选 ×5.8 + full-f 噪声,
   落入后一 regime——**形态是分类学的预言,不是意外**。二维额外贡献:
   全壳层各处独立成核 → 波包在空间上也重叠。
2. **为何波包短/停滞**:波包生于 0.25–0.4(弱压缩下低频走廊部分重开:
   B_th(0.25)≈6e-4 < B_opt),幅度在密集列车中很快到 B_opt 量级 →
   上爬时超出局地 B_opt 而脱锁(WHY_NO_060 的停止机制)+ 列车内相互
   干扰。
3. **为何 0.5 凹槽**(当前证据下的归因,H1 味):V_p(0.5)=\|V_R(0.5)\|
   简并把两条共振通道聚焦在同一群电子;热主体在 0.5 附近 \|V_R\| 最小
   → 与分布最稠密段共振 → **对非锁相波包的回旋吸收在 0.5 最强**
   (legacy band_ctrl_big 实测过的"control baseline valley")+ 走廊
   停止把功率堆在 0.5 以下。Landau/E∥ 通道(H2 的前半)**已强烈活跃**
   (台账 +18.8),但平台签名未熟——H2 式雕刻是否叠加,需 rel 修正后
   的干净长跑判定。
4. **为何 0.5 之上只有间歇斑块**:A=5 的线性增长带延伸到 ~0.8(直接
   线性激发持续补充),但被热主体在 0.55–0.6 的回旋吸收吃掉,未能
   积累成带(UB/LB 1.6%)。
