# RUN CARD(设计稿)— 真实尺度源区模拟 "P2-REAL"

2026-08-19 深夜设计,响应用户提问:"接近真实磁层、只模拟源区,行不行?"
结论:**行,机制上正是自然界自己的解法**——真实 lre 下 Omura 阈值
B_th ∝ lre⁻⁴ 掉到 4e-8(比任何模拟噪声都低),横向折射/走离 ∝ 1/L0
慢 17 倍,压缩几何的两个死结同时消失。代价见"风险"。

## 硬前提(必须先做,~半天)

**天线触发端口**(chirp2d 的 [antenna] 移植到 warden2d):
真实尺度下 full-f 散粒噪声(~1e-3)≫ B_th(4e-8)→ 全频带同时点火
= flood/hiss,离散元素没有出生机会。唯一出路是 **δf(安静底噪)+
天线注入一个胚胎**。δf 无自发辐射在这里反而是特性不是缺陷。
附带红利:δf 不沉积 f0 的磁化电流 → **抗磁凹陷问题自动消失**
(prebalance=0,V4R7-10 从未见凹陷)。

## 几何与参数

```

                                             # = 真实 L=5(ωpe/Ωe=5 标定)
[domain] lam_w=8 度(x_min=18170),dx=dz=0.25,margin=60
         active band [18580, 18980]
box 估算: x∈[18170,19040] × z∈[±2680] ≈ 3700×21500 格
         sparse 池 ~5.5e7 cells → fields ≈ 3.3 GB
[species engine] deltaf=1, rel=1, n0=0.010, uthpar=0.141, uthperp=0.345
         shell L0=18780, dL=100 (=10.4 λ∥ ✓), edge=10, ppc=60
         wdnoise=1e-5(压底噪,给元素让出时间窗)
         → ~5.0e8 markers ≈ 18 GB;总显存 ~21.5 GB ✓
[boundary] absorber 240 格;粒子墙 ±8°(镜比仅 1.03,见风险 R2)
[antenna] 赤道 shell 列,ω=0.25 Ωe_eq,δB≈1e-3 B0eq
         (≫B_th=4e-8,≪B_opt=8.4e-3,真实 chorus 触发幅度量级)
         ramp ~500/ωpe 后关断
[time] dt=0.15, nsteps=300000 → t=45000/ωpe=9000/Ωe
[diag] probe_every=4;probe_L2=18830;snap_every=1000;fv_vmax/uqmax=0.6/1.2
```

## 时间预算(真实尺度的物理就是慢)

- 真实 chorus 扫频率 ~3e-5 Ωe²(观测 df/dt≈10 kHz/s @ fce 7 kHz 换算)
- 一个元素 0.25→0.50 Ωe 需要 ~7800/Ωe;触发+演化 → 300k 步
- ~90 ms/step × 300k ≈ **7.5 小时,一次跑约一个元素**

## 冻结期望

- E1 注入包在关断后不衰减,锁相并开始上扫(判据:ridge 单调上升
  ≥3 个独立频点,跨 ≥1000/Ωe)
- E2 扫频率与 Omura(该 Bw、真实 a)一致(因子 2 内)
- E3 δf 健康:wd_rms < 0.25 全程(幅度 1e-3 级,远低于 V4R9 工况)
- E4 背景自发增长(见 R1)不淹没元素窗口

## 风险(诚实记录)

- **R1 背景竞速**:δf 底噪(wdnoise 1e-5)也会以 γ_linear 指数增长,
  ~11000/ωpe 后爬到触发幅度量级 → 元素必须在此之前完成主扫。
  缓解:早触发(t=500)+ 低 wdnoise;若仍竞速,底噪再降或减短跑。
- **R2 墙近似**:±8° 墙的镜比只有 1.03,绝大多数粒子靠墙反射而非
  磁镜折返 = "瞬时镜像"近似(省去真实的高纬往返延迟)。元素物理
  是赤道的、单元素时标 ≪ 弹跳周期,预计影响小,但这是本设计最大
  的物理近似,记录在案。
- **R3 单发成本**:7.5 h/元素;参数试错贵。首跑只求 E1/E3。
- **R4 若成功**,"真实尺度 + 触发"与"压缩尺度 + 约束"构成论文的
  两极对照;若 E1 失败(包不锁相),优先怀疑天线频率/位置匹配,
  其次才是机制问题。
